Documentation & User Guide

Everything you need to know about visual scraping, AI selectors, and dataset exports in WebScraperAI Studio.

⌨️ Native Keyboard Shortcuts

Speed up your scraping workflows using native macOS keyboard shortcuts:

Action Shortcut Description
Run Active Scraper ⌘ R Executes current extraction pipeline and pagination across all configured pages.
Magic Auto-Detect ⌘ D Scans page structure, detects recurring item clusters, and loads a preview table.
AI Extraction Prompt ⌘ K Opens the AI assistant to synthesize CSS selectors from plain English.
Export Dataset ⌘ E Opens the export dialog for CSV, TSV, JSON, Excel XML, or SQLite.
Toggle Studio Inspector ⌘ I Opens or closes the right-hand selector and pagination inspector sidebar.

🎯 Visual Scraping Modes

Browse vs Select Mode

In the top toolbar, use the segmented mode switcher:

  • Browse Mode: Use the browser canvas normally (click links, log in, perform searches, dismiss dialogs).
  • Select Mode: Hover over any item to highlight it. Clicking an item adds it to your extraction fields and automatically synthesizes a container and relative CSS selector.

Magic Auto-Detect (⌘D)

Click "Auto-Detect" or press ⌘D on any article feed, e-commerce catalog, or search result page. The engine analyzes DOM sibling trees, scores content richness (headings, links, prices, ratings), highlights the cards in green, and fills the dataset table with sample records.

📊 Dataset Studio & In-Place Cleaning

Column Quality Auditing

Click the Stats button in the dataset preview header to open the analytics drawer. Review column fill rates (detect missing data), distinct value counts, and automatic Min/Average/Max calculations for price and numerical columns.

1-Click Column Data Cleaning

Click the ... menu on any column header in the preview table to apply instantaneous transformations:

  • Clean Whitespace: Normalizes tabs, trailing spaces, and line breaks.
  • Extract Number Only: Strips letters and symbols, leaving clean decimal numbers (e.g., "$129.95 / each" → "129.95").
  • Strip Currency: Removes $, €, £, ¥, ₹, ₽ symbols.
  • Strip HTML Tags: Removes raw markup and preserves clean inner text.
  • Case Transformations: UPPERCASE, lowercase, and Title Case.
  • Copy Column Values: Copies all values in that column as newline-delimited text.

💾 Export Formats & Clipboard Sharing

WebScraperAI Studio supports five export formats with zero cloud dependencies:

  • CSV: Standard RFC 4180 UTF-8 with proper comma and quotation escaping.
  • TSV (Tab-Separated): Use the 1-Click "TSV (Excel)" button to copy table data and hit ⌘V to paste directly into Microsoft Excel or Apple Numbers.
  • JSON: Indented, pretty-printed JSON array of objects.
  • Excel SpreadsheetML XML: Native Excel workbook XML with colored headers and typed numeric cells.
  • SQLite 3: Standalone relational SQLite database file with automatic schema creation and indexed records.
